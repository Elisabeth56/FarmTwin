---
title: First run
description: Get FarmTwin's AI model by downloading it or importing it from a flash drive.
---

FarmTwin needs its AI model (about 2 GB) before it can answer questions. The first screen offers two ways to get it. Your farms, logs and risk checks work while you wait.

## Download the model

The download can pause and resume, so a dropped connection doesn't mean starting over. Use Wi-Fi if you can.

## Import from a flash drive

If someone already has FarmTwin, copy the model file (`.gguf`) from their laptop onto a flash drive. On your laptop, choose **Import model file** and pick it.

:::note[Every model is checked]
FarmTwin checks the file against a known fingerprint (SHA-256) before using it, so a damaged or wrong file is caught straight away.
:::

## Voice

Voice input isn't in the desktop app yet. Type your question in English or Pidgin; answers are in English.
