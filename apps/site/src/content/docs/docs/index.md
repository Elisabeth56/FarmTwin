---
title: Get FarmTwin running
description: Install FarmTwin, get its AI model once, and use it offline.
---

Install the app, get the AI model once, then everything works offline. Allow about ten minutes, plus the model download.

1. [Install](/docs/install/) FarmTwin for Windows, Mac or Linux.
2. On [first run](/docs/first-run/), download the model or import it from a flash drive.
3. Add your [farms and fields](/docs/farms/), [log](/docs/logging/) what you see, and [ask](/docs/asking/) about a farm.

Stuck? See [troubleshooting](/docs/troubleshooting/).
