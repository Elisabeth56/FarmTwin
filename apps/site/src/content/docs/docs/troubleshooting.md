---
title: Troubleshooting
description: Fixes for the problems people run into most.
---

## The model download keeps stopping

Leave FarmTwin open and it resumes from where it stopped. If your connection is too unreliable, get the model file from someone who has it and use **Import model file**.

## "Model file doesn't match"

The file is damaged or is a different model. Copy it again from the source laptop, or download it fresh.

## "The model stopped"

Usually the laptop ran low on memory while answering. Close other apps, especially browsers with many tabs, then click **Restart the model**. Your farms, logs and risks keep working meanwhile.

## The Mac says FarmTwin is damaged

Delete it from Applications, download the `.dmg` for your chip type again, and follow the **Open Anyway** steps in [Install](/docs/install/).

## Answers are very slow

The AI model needs a few gigabytes of free memory while it answers. Close other heavy apps and try again.
